# To-Do List App

Simple app built with Angular Signals, Angular Material, and Tailwind.

Helps you organize your tasks.

Angular Signals make the app more reactive.

Used `update()` to add or delete the main tasks list array in the ToDo App component.

Todo List component receives the tasks list as an input.

Used `computed()` to filter the tasks based on the status, Active or Done, and update the count of tasks. Also used `output()` for actions.

## To Run the Project

```bash
npm install
ng serve --open
